# Lesha Voice

Android-кликер с голосовой командой STOP: отдельное слово **«Лёша»** (или «Леша») от любого говорящего останавливает автоматические нажатия. Обучение голосу и запись образца не нужны.

## На телефоне

1. Установите debug APK, откройте «Лёша» и нажмите **«Разрешить нажатия»**. В специальных возможностях включите **«Лёша · нажатия»**.
2. Нажмите **«Выбрать точку»**, откройте нужное приложение обычным способом, перетащите центр прицела на нужное место и нажмите **«Сохранить»**. Окна выбора занимают только прицел и панель; остальной экран доступен.
3. Вернитесь в «Лёша», задайте интервал (100–60 000 мс), нажмите **«СТАРТ»**, разрешите микрофон и уведомления. Есть 3 секунды, чтобы перейти на нужный экран. Нажатия начнутся только после готовности распознавания.
4. Скажите **«Лёша»**. Клики останавливаются сразу после первого подходящего промежуточного или окончательного результата распознавания. Ручной **STOP** есть в приложении и в уведомлении.
5. Чтобы продолжить, снова нажмите **«СТАРТ»**. После поворота экрана выберите точку заново.

Сервис нажатий не читает содержимое экрана. Микрофон используется только во время явно запущенного сеанса. Закрытие приложения через список недавних, выключение экрана, отключение сервиса нажатий и ошибки распознавания останавливают сеанс.

## Границы поведения

- Нужен Android 8.0+ и установленный системный сервис распознавания, поддерживающий русский язык. Его точность и задержка зависят от телефона, условий записи и доступности сети. Приложение не проверяет личность говорящего. Это не гарантия распознавания каждого произнесения.
- Сохранён системный `SpeechRecognizer`: он работает сеансами, а не как непрерывный офлайн-детектор. Между сеансами и на время ожидания окончательного результата клики стоят на паузе; после готовности микрофона возобновляются. Ошибки связи/микрофона требуют нового ручного старта. Если один сеанс не заканчивается за 30 секунд, кликер останавливается, чтобы не продолжать работу с зависшим распознавателем.
- STOP синхронно отменяет все будущие нажатия и исключает перезапуск от старых таймеров и callback. Уже отправленное Android нажатие длительностью 1 мс отозвать этим API нельзя; новых жестов после обработки STOP не отправляется.
- Интервал — пауза после подтверждения предыдущего нажатия; одновременно отправляется не более одного жеста.
- Если Android сообщает об ограниченных настройках для установленного APK, разрешите их в системной карточке приложения, затем вернитесь в специальные возможности.
- Debug APK разных сборок может иметь разные тестовые подписи. При конфликте подписи сначала удалите предыдущую debug-версию (настройки точки и интервала будут удалены).

## Сборка и проверки

JDK 17, Gradle 8.9, Android SDK Platform 35. В корне репозитория:

```sh
gradle testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions выполняет эти проверки для `main`, pull request и ручного запуска. APK находится в artifact **Lesha-Voice-debug** на странице успешного запуска.

Unit-тесты проверяют слово STOP, ложные совпадения, остановку до первого клика, просроченные таймеры/ответы жестов, новый запуск после STOP и паузу/возобновление. Для проверки на устройстве: убедитесь, что клики идут на тестовом экране; произнесите «Лёша» разными голосами и внутри фразы; дождитесь минимум двух интервалов без новых кликов; проверьте повторный ручной старт, STOP из уведомления, выключение экрана и отключение распознавания. Реальную акустику и поведение системного распознавателя нужно проверять на телефоне.

Документация Android: [SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer), [события распознавания](https://developer.android.com/reference/android/speech/RecognitionListener), [foreground microphone](https://developer.android.com/develop/background-work/services/fgs/service-types#microphone), [dispatchGesture](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService#dispatchGesture(android.accessibilityservice.GestureDescription,%20android.accessibilityservice.AccessibilityService.GestureResultCallback,%20android.os.Handler)).
